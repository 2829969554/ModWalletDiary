# ModWalletDiary · 钱包日记

离线个人记账应用：纯前端 JS 实现，所有 JS 库已下载到本地（`lib/`），**无需联网即可运行**。

## 快速开始

方式一（推荐）：任意静态服务器

```bash
cd ModWalletDiary
python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

方式二：直接双击 `index.html` 也可以使用（file:// 协议下品牌图标 SVG 拉取会被浏览器拦截，自动回退为"随机颜色 + 文字"图标，不影响其它功能）。

## 功能

| 页面 | 说明 |
|---|---|
| 仪表盘 | 今天是今年第几天 / 距年尾 / 距过年；今年、本月收入支出四个圆环；信用卡类账单日临近一周顶部**还款提醒横幅**（已还款 / 临时关闭）；时光轴明细（带支付工具 LOGO） |
| 我要记账 | 日期、类型（收入1/支出2）、款项名目、支付工具、交易路径（线上1/线下2）、商户名称（可自定义） |
| 款项名目 | 增加 / 重命名 / 隐藏（隐藏后可恢复）；序号 mid 只正向增加不复用 |
| 支付工具 | 增加 / 重命名 / 隐藏（可恢复）；序号 qid 只正向增加不复用；市面常见工具自动匹配 LOGO；信用卡 / 花呗 / 借呗 需填写**账单日**；手机端新增卡片默认隐藏，右下角悬浮按钮（+）打开新增弹窗 |
| 统计 | 3年 / 1年 / 半年 / 3个月，或指定月份、指定周；按款项名目汇总支出与收入 + 分布图 |
| 管理 | 导出（WalletDiary 数据文件下载到本地）/ 导入（**合并式**：同名名目/工具沿用现有编号、账单去重续号，仍用当前密码保存；**覆盖式**：完全替换当前数据，解锁密码变为文件原密码。**文件密码与当前密码不同时会弹出密码输入框**，输入文件密码验证通过后才能导入）/ 修改密码（老密码解密 → 新密码加密回写 → 刷新） |

## 数据与加密

- 存储位置：`localStorage`，键名 **`WalletDiary`**（json 树总命名，其余为分类名：`walletdiary` 账单、`mingmu` 款项名目、`gongju` 支付工具、`shanghu` 商户、`meta` 元数据）。
- 储存格式：全部数据的 JSON 文本 → **AES 加密 → Base64** 保存。
- 首次打开需设置密码（两遍一致），默认数据用该密码加密后写入；以后每次打开需输入密码解锁。
- 修改密码：从 `WalletDiary` 读取密文用老密码解密，再用新密码加密回写，然后刷新页面。

账单字段：`wid`（序号）、`wtime`（日期时间）、`wyear`/`wmon`/`wday`（年/月/日）、`wtype`（1收入/2支出）、`wname`（款项名目编号）、`wtool`（支付工具编号）、`wqtype`（1线上/2线下）、`wpayname`（商户名称）、`wamount`（金额）、`wnote`（备注）。

工具额外字段：`qday`（账单日，1-31，仅信用卡/花呗/借呗）、`qpaid`（已标记还款的账单日，用于还款提醒去重）。还款提醒逻辑：账单日距今 ≤7 天且未标记本期已还款时，仪表盘顶部显示橙色横幅；「已还款」记录本期账单日、到下期临近时再提醒；「临时关闭」仅本次会话隐藏（刷新后恢复）。

## HBuilderX 打包安卓 APK（H5 runtime plus）

1. HBuilderX 新建"5+App (Wap2App / 原生APP-本地HTML)"项目，或直接把本目录作为本地 HTML 资源导入（`manifest.json` 已含 `app-plus` 配置）。
2. 云打包为安卓 APK。
3. 系统返回键行为：**双击返回退出**（2 秒内按两次返回键退出，第一次弹 toast 提示"再按一次退出应用"），顶部自动适配 `safe-area-inset-top`。
4. 导出在 APP 环境会写入公共文档目录（`plus.io.PUBLIC_DOCUMENTS`）。

## 图标说明

常用支付软件/平台/银行品牌图标已**本地内置**在 `js/brand-icons.js`（37 个，离线可用），SVG 数据采集自 Iconify 聚合图集（Simple Icons CC0、Remix Icon Apache-2.0、Arcticons GPL-3.0、Logos MIT）。覆盖：支付宝/花呗、微信/微信支付、QQ、京东/京东白条、拼多多、淘宝、饿了么、抖音、快手、小红书、百度、网易云、云闪付（银联三色标）、滴滴、唯品会，工商/建设/农业/中国/招商银行，华为、小米、Apple/Apple Pay、Visa、万事达、PayPal、Stripe、Steam，星巴克、瑞幸、肯德基、麦当劳等。

运行时按名称关键词匹配显示品牌图标；内置库没有的品牌回退为"随机颜色 + 首字"图标（哈希取色，稳定）。重新采集/扩充：`node build-icons.mjs`。
